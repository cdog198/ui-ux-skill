# Sevenhalf Lab

Rebuild of sevenhalflab.com: an independent film production house in Naples.
Next.js (App Router, static export), TypeScript, Tailwind CSS v4. Italian only, like the current site.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # writes the whole site to /out (plain HTML/CSS/JS, any static host)
npm run lint
```

## Where things live

| What | File |
| --- | --- |
| Films: credits, synopsis, festivals, awards, poster, stills, trailer | `content/films.ts` |
| Page copy, contacts, socials, galleries | `content/site.ts` |
| Content types (what a film can have) | `content/types.ts` |
| Design decisions and references | `DESIGN_NOTES.md` |
| Colours and type | `src/app/globals.css` (`@theme`) and `src/app/layout.tsx` |
| Images (all from the live site's `/wp-content/uploads/`) | `public/media/` |

All copy is verbatim from the live site. Fields the site doesn't state are `null` with `// TODO: ask client`.
Search for `TODO: ask client` to get the list of open questions. Lines rewritten for layout are marked `// new:`.

### Adding a film

Add an entry to `films` in `content/films.ts`, put the poster in `public/media/posters/` (2:3) and stills in
`public/media/stills/`. It appears on the homepage wall, in its format page (`/corti/`, `/documentari/`, `/serie/`) and
gets its own page at `/film/<slug>/`. To add a `lungometraggi` page, add it to `formats` in the same file.

### Turning the reels into real loops

`<Reel>` (`src/components/Reel.tsx`) plays a muted mp4 when given `video="/media/loops/<file>.mp4"`; until then it
shows a real still with a slow drift. Keep clips 6–10 s, about 1920px wide, no audio track, under ~3 MB.

## URLs

The old WordPress URLs keep working: `/film/<slug>/`, `/cinema/`, `/subacquea/`, `/commercial/`,
`/distribuzione-indipendente/`, `/chi-siamo/`, `/contatti/`. The old `/film-distribuzione/<slug>/` pages forward to
`/film/<slug>/`, which now holds both production and distribution details. On Vercel, `vercel.json` turns these into
real 301 redirects. On another host, add the same rule there.

## Deploy on Vercel

Import the repo at vercel.com/new and set **Root Directory** to `sevenhalflab`. Leave the rest at the defaults (Next.js is
detected). Then add `sevenhalflab.com` under Settings → Domains and point DNS as Vercel shows. Only switch DNS when the
WordPress site can go offline.
